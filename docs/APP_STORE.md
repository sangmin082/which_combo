## 2. 프로모션 텍스트 (170자)

> 5×5 게임판에 흩어진 스물다섯 개의 숫자. 위치는 오직 당신의 기억에만 있다. 외운 자리로 족보를 만들어 승점을 쟁취하라 — AI와의 두뇌 대결부터 방 코드 하나로 시작하는 친구와의 실시간 승부까지.

## 3. 설명

> 🎲 스물다섯 개의 숫자, 그리고 오직 기억력만으로 벌이는 족보 승부.
>
> 「위치, 콤보!」는 화제의 1:1 암기 대결을 모바일로 옮긴 두뇌 게임입니다.
>
> ◆ 게임 방법
> • 배치 — 주사위(1~10)를 굴려 나온 숫자를 내 5×5 게임판에 하나씩 배치합니다. 총 25칸.
> • 암기 — 배치가 끝나면 숫자는 모두 가려집니다. 어디에 무엇을 놓았는지는 오직 머릿속에만. 기록하면 몰수패!
> • 족보 제출 — 가로/세로/대각선으로 이어진 4칸을 골라 족보를 선언합니다. 12라운드, 제한 시간 1분.
> • 족보 순위 — 쿼드 > 로얄 스트레이트 > 스트레이트 > 투페어 > 트리플 > 원페어 > 하이.
> • 승리 — 라운드마다 더 강한 족보가 승점을 가져가고, 12라운드 뒤 승점이 높은 쪽이 승리합니다.
>
> ◆ 특징
> • 배치부터 시작되는 전략 — 같은 숫자를 모아 쿼드를, 연속 숫자를 순서대로 놓아 로얄 스트레이트를 설계하세요
> • 기억력이 불완전한 인간적인 AI — 난이도 3단계
> • 방 코드 하나로 친구와 실시간 온라인 대결
> • 이미 쓴 조합은 재사용 불가 — 어느 라인을 어느 라운드에 소모할지가 승부처
> • 스크린샷을 찍으면? 규칙대로 몰수패입니다. 진짜로.
>
> 스물여덟 개의 라인, 열두 번의 선언. 당신의 기억은 마지막 라운드까지 버틸 수 있습니까?

## 7. 심사 정보 (App Review Information) — 메모란에 붙여넣기

> This is a 1v1 memory board game.
>
> • All features can be fully tested in SINGLE PLAYER mode (혼자 하기) — no account or login required.
> • The 2-player mode (둘이 하기) requires two devices: one creates a room and shares a 6-digit code, the other joins with the code. Single player is sufficient to review all mechanics.
> • NOTE: Taking a screenshot DURING a match intentionally causes an immediate game forfeit — this is a core game rule ("no recording allowed"), not a bug.
> • The app contains no ads, no in-app purchases, and collects no data.

## 8. 스크린샷 (사용자 작업)

- 기기: 본인 iPhone(6.9형)에서 찍은 스크린샷이 규격(1320×2868)과 정확히 일치 — 그대로 업로드 가능
- 최소 1장, 추천 4~5장:
  1. 홈 화면
  2. 배치 단계 (주사위 값과 내 게임판 숫자가 보이는 순간)
  3. 족보 제출 단계 (라인 선택 하이라이트)
  4. 라운드 판정 순간 (양쪽 족보 공개 연출)
  5. 승리 화면 (전체 게임판 공개)
- ⚠️ 게임 중 스크린샷은 몰수패가 되지만 **스크린샷 자체는 정상 저장**됩니다 — 버리는 판에서 찍으세요
